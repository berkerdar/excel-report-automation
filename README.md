# Excel Report Automation

Turns a folder of messy monthly sales exports into a clean, formatted Excel report in one command.

**The problem:** Every month someone merges CSV exports from several branches by hand, fixes the dates, removes the duplicate lines and rebuilds the same pivot tables and charts.

**What the script does**
- Merges every CSV in a folder
- Cleans the data: inconsistent branch names (`  ANKARA KIZILAY ` → `Ankara Kizilay`), comma decimals (`420,00`), missing quantities, duplicate receipt lines
- Handles mixed date formats safely. ISO `2026-08-01` and Turkish `01.08.2026` / `01/08/2026` appear in the same file. A naive day-first parse turns `2026-08-01` into 8 January, so each format is parsed explicitly.
- Builds an Excel workbook with:
  - **Monthly by Branch:** pivot table + line chart
  - **Products:** units and revenue + bar chart
  - **Clean Data:** the cleaned rows, formatted
  - **Data Quality:** what was fixed or removed, so nothing disappears silently

## Run it
```bash
pip install pandas openpyxl
python make_sample_data.py          # creates sample input/ files (skip with real data)
python report.py --input input --output sales_report.xlsx
```
